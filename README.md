# UCash · 线上小额现金贷系统

> Flutter 安卓客户端 + Node/Express/SQLite 业务中台 + React 运营后台，三端同仓，功能闭环（非界面演示）。

## 一、系统组成

| 模块 | 目录 | 技术栈 | 端口 |
|---|---|---|---|
| 借款人 App | `apps/mobile_flutter` | Flutter 3.x / Dart 3.13 / Material 3 | — |
| 业务中台 | `apps/server` | Node 22 + Express 4 + TypeScript + better-sqlite3 | 4000 |
| 运营后台 | `apps/admin` | Vite 5 + React 18 + TypeScript | 5173（开发）/ `/admin`（生产） |

可视化规范：深藏蓝 `#0F2B5B` 主色 + 香槟金 `#C9A45C` 强调 + `#F5F6F8` 页面底 + 白色圆角卡片，语义色成功绿 / 警示红，与 `design-preview/` 七张设计稿一致。

## 二、快速启动

```bash
# 1. 安装依赖（首次）
npm run install:all

# 2. 初始化数据库与演示数据（--reset 会清空重建）
npm --prefix apps/server run seed -- --reset

# 3. 启动业务中台（终端一）
npm run dev:server
# → http://localhost:4000  健康检查 /health

# 4. 启动运营后台（终端二）
npm run dev:admin
# → http://localhost:5173

# 5. 运行 Flutter App
cd apps/mobile_flutter
flutter run            # 连接安卓设备 / 模拟器
```

后台已构建时，也可直接访问 `http://localhost:4000/admin`（由中台托管 `apps/admin/dist`）。

### 安卓端网络配置

| 运行环境 | 默认 API 地址 | 说明 |
|---|---|---|
| Android 模拟器 | `http://10.0.2.2:4000` | 代码内自动识别 |
| 真机（同一局域网） | `http://<电脑IP>:4000` | 设置页 → 开发者选项 → 修改服务端地址 |
| Flutter Web | `http://localhost:4000` | 自动识别 |

清单已开启 `usesCleartextTraffic` 与 `network_security_config`，支持本地 HTTP 联调；生产切换 HTTPS 后关闭即可。

## 四、功能范围

### C 端（Flutter）

- **账号**：手机号 + 短信验证码登录/注册、密码登录、协议勾选、注销账户
- **认证**：三要素实名（身份证校验位 + 年龄 22–55 + 学生拦截）、活体人脸（模拟通道）、双紧急联系人授权、公积金/运营商/信用卡账单提额认证
- **授信**：认证进度、自动风控决策（通过 / 拒绝 / 转人工）、额度与定价、拒绝原因、额度有效期
- **借款**：500–50,000 元滑块、3/6/12 期、等额本息试算、IRR 明示、优惠券抵扣、收款卡选择、合同签署、防改价 quoteToken
- **放款**：审核 → 放款中 → 到账状态机，失败码 E1024 + 换卡重试，服务重启自动补偿
- **账单**：本期应还、待还/已还/全部、期供明细、逾期天数与罚息
- **还款**：按期还款、提前结清（免未来利息）、还款凭证、额度实时释放
- **我的**：额度三栏、借款/还款记录、银行卡管理、优惠券、邀请有礼、消息中心、帮助与客服、设置

### B 端（运营后台）

- 工作台：今日放款/还款/新增用户、在贷余额、逾期率、授信通过率、7 日趋势、健康度阈值提示
- 授信审批：风控快照、命中规则明细、人工定额定价、通过/拒绝
- 借款订单：状态筛选、搜索、详情（还款计划 + 流水）、人工放款/拒绝
- 账单与逾期：逾期台账、罚息减免（审计留痕）、手动逾期扫描
- 还款流水、用户管理（调额/冻结/黑名单）、风控规则开关、决策回溯、优惠券、运营配置、审计日志

## 五、核心算法口径

| 项 | 口径 |
|---|---|
| 还款方式 | 等额本息：每期利息按剩余本金计息，末期本金取剩余全部平账 |
| 每期金额 | `月供 = P·i·(1+i)^n / ((1+i)^n − 1)`，`i = 年利率/12`，全整数分四舍五入 |
| 综合年化 | IRR：现金流 `[-P, 每期还款…]` 二分法求月利率，年化 `(1+r)^12 − 1` |
| 罚息 | 逾期本息 × 日万分之五 × 逾期天数 |
| 提前结清 | 剩余本金 + 当期未付利息 + 已产生罚息（免未来利息） |
| 额度模型 | 收入档位 + 认证项加成 × 评分系数，封顶 5 万，500 元取整 |
| 定价模型 | 评分档位 10.8%–23.99%，资质认证降息，下限 9%，上限 24% |

账务自洽校验（E2E 脚本内置断言）：`Σ每期本金 = 借款本金`、`Σ每期应还 = 总应还`、`实际 IRR ≤ 24%`。

## 六、端到端验收

```bash
npm run dev:server      # 终端一
npm run e2e             # 终端二
```

脚本覆盖：注册 → 实名 → 人脸 → 联系人 → 提额 → 授信 → 试算 → 下单 → 放款 → 账单 → 还款 → 提前结清 → 额度释放 → 流水 → 站内信，共 27 项断言（含还款幂等、流水账务自洽）。

## 八、构建 APK

```bash
cd apps/mobile_flutter
flutter build apk --release
# 产物：build/app/outputs/flutter-apk/app-release.apk
```

- 正式包需替换 `android/app/build.gradle.kts` 中的签名配置（当前使用 debug 签名）
- 上架国内应用商店需：软件著作权、ICP 备案、等保测评、金融类目资质报备
- 打包前将 API 地址改为生产 HTTPS 域名，并移除明文流量允许配置
